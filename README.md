# AI Image Generator

A modern and responsive AI Image Generator web application built with HTML, CSS, and JavaScript.

## Features

- Clean and modern UI
- Responsive design for desktop, tablet, and mobile
- Dark mode support
- Prompt input with random prompt generator
- Model selection
- Image count and aspect ratio controls
- Loading, success, and error states
- Download generated images

## Upcoming Features

- AI image generation via API integration
- Dynamic image gallery updates
- Prompt history
- Enhanced image customization options

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome

🚧 Frontend UI completed. AI generation functionality is currently in development.
